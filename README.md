# X Pro VPN

Premium VPN desktop application with a sleek black & white design.

## Features

- **Beautiful UI** — Modern dark/light theme with smooth animations
- **20 Server Locations** — US, UK, Germany, Japan, and more
- **Real-time Speed Monitoring** — Live download/upload graph
- **VPN Protection** — DNS encryption via Cloudflare (1.1.1.1)
- **Kill Switch, DNS Leak Protection, Split Tunneling**
- **WireGuard / OpenVPN / IKEv2 protocol selection**

## Download

Go to [Releases](../../releases) and download `X-Pro-VPN-Windows.zip`.

### How to Run

1. Extract `X-Pro-VPN-Windows.zip`
2. Open the `win-unpacked` folder
3. Run `X Pro VPN.exe`

> Windows SmartScreen may show a warning on first launch — click "More info" → "Run anyway"

## Build from Source

```bash
npm install
npm run build:win
```
